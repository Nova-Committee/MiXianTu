## 定位

本页收**服务端配置项**：它们都在游戏内的「配置 → 服务端」界面里按标签页分，改完即时生效（服务端每次都读当前值，不缓存），**它们不是命令**。本页给的是配置项名与键名（配置文件 `config/mxt/mxt-server.json`），口径以代码为准。

各标签页在配置文件里就是一个段，段名与游戏里的标签页同名（`talisman`、`alchemy`……）；键名与界面上的条目一一对应。

## 符箓

画符工作站用的十项，加一条本来就有的使用冷却。判定用的时间一律是**服务端收到包时的游戏刻**，客户端报上来的时间与用量都不读。

| 键 | 默认 | 口径 |
| --- | --- | --- |
| `talisman.min_stroke_interval` | `300`（毫秒） | 相邻两笔之间、以及"开画 → 第一笔"之间的最小间隔；`0` 关闭。低于它的那一笔**被拒收**（客户端必须把那一笔抹掉，否则结算对账会挂）。它拦得住"一瞬间灌进几百笔"，**拦不住按节奏自动描图的脚本**。 |
| `talisman.max_rejected_strokes` | `3` | 一次绘制里被拒的笔数超过它，本次会话判失败（材料不退）。只有"过快"与"颜料不够"计入；"光标上已经没有那支笔了"不计。 |
| `talisman.max_stroke_points` | `512` | 单笔点数上限；超了这一笔被拒收。 |
| `talisman.max_session_points` | `4096` | 一次绘制的累计点数上限；超了整次提交被拒收并记一条 warn。 |
| `talisman.max_session_strokes` | `64` | 一次绘制的笔画数上限；同上。 |
| `talisman.brush_capacity` | `4000` | 一支符笔能装多少颜料，单位＝像素弧长。一张 90×210 的符笔画总长通常在 400–1200，所以默认约能描满 3–5 张。 |
| `talisman.pigment_per_item` | `1000` | 一份颜料（`#mxt:brush_pigment` 标签里的一个物品，默认只有朱砂）蘸进符笔后给多少颜料。 |
| `talisman.pigment_rate` | `1.0` | 每像素弧长扣多少颜料。 |
| `talisman.pigment_floor` | `1` | 每一笔至少扣多少，免得"点一下"不花钱。 |
| `talisman.pigment_cap` | `0` | 单笔最多扣多少；`0` 表示不封顶。 |
| `talisman.use_cooldown` | `20`（刻） | 徒手激发符箓后的物品栏冷却；`0` 不加冷却。冷却按物品算、对该玩家的所有符箓生效，冷却期间长按灌注也会被拒绝。 |

判分参数（`pattern.tolerance` / `judgement`）**不是配置项**：它们跟着符方写在配方 JSON 里，见[符箓完成度判定](../../符箓完成度判定.md)；符笔与符纸的行为见[内置物品与组件](items)。

## 炼丹

| 键 | 默认 | 口径 |
| --- | --- | --- |
| `alchemy.toxicity_decay_per_second` | `0` | 有限非负数。默认不消退；设成正数后，只对已经有且不为 0 的丹毒、每累计 20 个实体活跃 tick 减一次。离线不减，也不给没服过丹的实体建立附件。 |

## 命令别名

「命令别名」标签页每一项就是一个顶层别名命令（条目名就是命令本身），默认全开。关掉只移除顶层写法，`/mxt` 下的入口始终完整——见[命令](commands)。
