判定标准：

- **完成**：注册表已完成，所有字段已接入，并能形成完整的服务端闭环。
- **制作中**：已完成大部分注册表和字段接入，但仍缺少闭环所需的消费者、入口或跨模块联动。
- **预留**：只有部分数据结构、类型分派或资源，主要逻辑尚未写入。

## 测试数据覆盖

测试模组 `src/test-mod` 为上述 31 个有效动态注册表各提供至少一个 JSON。`material_grade` 已从主代码和注册表索引移除；测试资源中若残留同名空目录，也不属于当前有效注册表。此次补充：

- `ability/firebolt.json`：以直接内联字段覆盖求和、均匀随机、二项分布和加权选择的嵌套解析。
- `creature_profile/spirit_wolf.json`：补充狼实体、实体标签、元素引用/标签、最低灵气和内丹，以覆盖实际选择与应用路径。
- `currency/iron_nugget.json`：覆盖物品与物品标签混合匹配。
- `spirit_herb/fire_ginseng.json`：覆盖现有物品与物品标签混合绑定，不创建专属灵植物品。
- `resource/*.json` 的 `bars`：覆盖目标条、Boss 位置条和同资源替换规则。
- `MxtTestMod`：服务端启动时验证灵气视觉配置、灵植物品匹配和原版结构模板阵法校验。
- `tags/entity_type/spirit_wolves.json`、`tags/item/currency_nuggets.json`、`tags/mxt/element/warm_elements.json`：为上述标签引用提供可解析成员。

JSON 已通过 PowerShell `ConvertFrom-Json` 校验；完整项目构建结果以本次修改后的 IDEA rebuild 为准。
