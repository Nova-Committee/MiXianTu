# 模块实现审计

**此文档已过时，新版：https://docs.qq.com/sheet/DWW9qRU1ST2Nob3Z5**

审计日期：2026-08-20。

本项目目前注册 **31 个原版 NeoForge 数据包注册表**。本文件将“通用数据驱动能力”与具体玩法拆开记录，避免某个玩法复用了成熟的
Action、Condition 或 NumberProvider 后，被误判为这些基础能力尚未实现。

## 判定标准

- **完成**：定义、所有字段的运行时消费者、存储/同步和入口已构成服务端闭环。
- **制作中**：定义与大部分运行时已存在，但至少一个字段、入口或下游联动没有消费者。
- **预留**：仅有数据结构、固有类型表或资源；尚未形成主要玩法闭环。
