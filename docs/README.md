# docs/ —— 仓库内的开发文档（**不是**玩家文档站）

本目录是 MiXianTu **仓库自带的开发文档源**：写给数据包作者、KubeJS 脚本作者与模组开发者看的中文文档，Docusaurus 风格（front matter + `_category_.json`），**在本仓库里不参与构建**。

**玩家文档站在另一个仓库**：<https://github.com/IAFEnvoy/mxt-docs>（VitePress，中文根路径 + `/en/` 英文镜像，也就是线上那份）。两边别搞混：

| | 本目录 `docs/` | 文档站仓库 `mxt-docs` |
| --- | --- | --- |
| 读者与语言 | 内容作者 / 开发者，中文 | 玩家，中英双语 |
| 内容 | 字段总表、模块审计、分篇指南、AI 速查 | 整理过的用法说明与教程 |
| 权威性 | 字段级权威是 `数据包格式.md` | 面向玩家的转述，权威仍在代码与 `数据包格式.md` |
| 改了一处 | 字段 / 命令 / 配置名变化时，另一边的对应页也要改 | 同上 |

一句话：**别把这里当成文档站**，也别把文档站的页面抄回来当权威；字段以代码和 [`数据包格式.md`](数据包格式.md) 为准。

## 目录里有什么

- [`数据包格式.md`](数据包格式.md)：所有数据包注册表与配方类型的字段总表，**字段级唯一权威**。
- [`getting-started.md`](getting-started.md)、`guide/**`：安装、游玩、数据包、KubeJS、Java 的分篇指南。
- [`ai/SKILL.md`](ai/SKILL.md)、[`ai/FORMAT.md`](ai/FORMAT.md)：给 AI 协作与本目录写作用的速查和格式规范；根目录的 [`SKILL.md`](SKILL.md)、[`FORMAT.md`](FORMAT.md) 是它们的短入口。
- [`kubejs物品示例.md`](kubejs物品示例.md)、[`物品灵气数据包.md`](物品灵气数据包.md)：被 `数据包格式.md` 引用的两个专题页。

每个模块做到哪一步、还缺什么**不在这个目录里**：看仓库根两份 README 的「模块完成情况 / Module Status」表（**完成度以代码为准**）。
