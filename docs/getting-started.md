## 基本信息

| 项目 | 当前值 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.99` |
| Java | `25` |
| Mod ID | `mxt` |
| 许可证 | `All Rights Reserved` |

项目仍在开发中（版本号以你装的那份 Jar 为准，本文档不绑定某个版本），数据包 Codec、附件和网络协议暂不承诺旧版本兼容。

## 前置要求

- NeoForge `26.1.2.99` 或更高版本（模组声明的最低版本）。
- Curios API `15.0.0+26.1.2`，必需前置。
- KubeJS `26.1.2-8.0.4`，仅在使用脚本扩展时需要。
- JEI、Jade 为可选兼容模组。

Curios API 会随开发构建通过 Jar-in-Jar 方式打包，但开发环境仍建议按 Gradle 配置准备对应版本。

## 配置

所有配置都在**游戏内的配置界面**里修改：打开**模组列表 → 觅仙途 → 配置**，界面顶部可以在「客户端设置」与「觅仙途服务端配置」之间切换。不需要、也不建议手改 `config/` 下的文件。

| 部分 | 权限 | 包含的标签页 |
| --- | --- | --- |
| 客户端设置 | 无（只影响本机） | 轮盘选择、资源条、人物信息面板、功法、裂隙、提示框 |
| 觅仙途服务端配置 | **OP** | 饰品栏、修炼、寿元、转世、符箓、灵气、阵法、命令别名、兼容 |

服务端配置改完会同步给已连接的客户端。本文档提到配置时一律写作**服务端配置「标签页 → 条目」**或**客户端配置「标签页 → 条目」**，按这个名字在界面的对应标签页里找即可。

## 开发运行

```bash
gradlew runClient
gradlew runTestClient
gradlew runTestServer
```

`runTestClient` 加载 `src/main` 和 `src/test-mod`，用于手动验证数据包和客户端显示；测试模组不会打入正式 Jar。

## 模块完成度

- **完成**：注册表、字段和运行时消费者形成闭环。
- **制作中**：大部分字段已接入，但缺少必要消费者或跨模块闭环。
- **预留**：仅有数据结构、Codec 或客户端预留，没有完整运行时逻辑。

| 模块 | 状态 | 说明 |
| --- | --- | --- |
| 动态注册表与 Codec | 完成 | 原版数据包注册表、Holder 引用、禁用标签和类型分派。 |
| 资源与境界 | 完成 | 资源条、境界链、修炼资源、寿元账本与服务端同步。 |
| 灵气环境 | 制作中 | 灵气查询、区块缓存、方块/物品灵气和 HUD 已接入；灵植、炼丹和自然生成规则仍缺少完整消费者。 |
