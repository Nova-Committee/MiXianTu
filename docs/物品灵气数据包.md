# 物品灵气数据包

`mxt:item_aura` 将已有物品定义为修炼期间使用的灵气燃料。文件位于：

```text
data/<命名空间>/mxt/item_aura/<路径>.json
```

```json
{
  "items": ["mxt:spirit_stone", "#example:spirit_fuel"],
  "total_aura": 100,
  "consume_speed": "0.5 + level * 0.05",
  "result_stack": {
    "id": "mxt:medium_spirit_stone",
    "count": 1
  },
  "exhausted_action": {
    "type": "mxt:apply_effect",
    "effect": "minecraft:fire_resistance",
    "duration_ticks": 40
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `items` | `ItemMatcher` | 必填。单个物品 ID、物品标签，或两者的混合数组。 |
| `total_aura` | `NumberProvider` | 必填。消耗一件物品时装入燃料条的灵气总量。必须在实际运行时求得正数。 |
| `consume_speed` | `NumberProvider` | 必填。燃料条每游戏刻消耗的灵气量。必须在实际运行时求得正数。 |
| `result_stack` | `ItemStackTemplate` | 可选。配置后，消耗燃料物品时向玩家物品栏加入该物品堆；未配置时只扣除原物品。 |
| `exhausted_action` | `EntityAction` | 可选，默认无操作。当前装入的灵气被耗尽时对修炼者执行。 |

灵气燃料条当前只作为隐藏的服务端状态，初始为空。每个服务端 tick，若条为空，系统按主手、再副手的顺序寻找匹配物品并消耗一件，将其 `total_aura` 装入条中；不要求一次装满任何固定容量。若定义了 `result_stack`，消耗时会额外向玩家物品栏加入该堆物品；未定义时只扣除原物品。随后使用该次装入的 `item_aura` Holder 计算 `consume_speed` 并扣减，直至耗尽，再执行 `exhausted_action`。

该燃料状态属于实体 `SpiritData` 附件，包含当前 `item_aura` Holder、剩余值和本次装入总量，并由服务端同步到客户端。客户端目前不渲染燃料条，也不自行扣除或消耗物品。和其他数据包注册表一致，可通过 `data/mxt/tags/mxt/item_aura/disabled.json` 停用条目。
