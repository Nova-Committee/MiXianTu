# 测试设定参考

本目录用于整理公开小说介绍、百科说明和社区设定资料中反复出现的修仙/玄幻设定，以便后续构造数据包、KubeJS 与运行时集成测试。

这里不是策划案：

- 不将任何来源中的名称、数值、世界观或剧情作为项目正式内容。
- 不要求实现每一项设定；清单只标识架构必须能够承载或明确拒绝的测试面。
- 不复制小说正文，仅以概括方式记录常见模式并保留来源链接。

文件说明：

- `00_来源与阅读记录.md`：本轮在线检索过的公开资料及其可用范围。
- `01_常见设定与功能测试面.md`：常见设定到运行时功能的映射。
- `02_集成测试场景矩阵.md`：后续可实现为数据包/游戏测试的场景组合。

资料访问日期：2026-07-30。
