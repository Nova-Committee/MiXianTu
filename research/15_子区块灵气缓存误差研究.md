# 16×16×16 子区块单方块灵气缓存研究

## 目的

评估子区块缓存把一个灵气方块近似到子区块中心时产生的误差，并单独观察这个方块本身的实际灵气影响。

本次采用 `1/r^2` 衰减。当前运行时代码仍使用 `1 / (1 + distanceSquared)`，本研究不修改运行时代码。

## 正确的单方块模型

每个样本只放置 **一个** 灵气方块，不再把 4096 个方块同时当成灵气源。

- 子区块包含 4096 个可能的方块中心，坐标为 `-7.5 ... 7.5`。
- 方块缓存算法把这个方块视为子区块中心 `c`：

  `A_cache(q) = 1 / |q - c|^2`

- 实际算法使用方块的真实位置 `p`：

  `A_exact(q, p) = 1 / |q - p|^2`

- 误差是两者的绝对差：

  `E(q, p) = |A_cache(q) - A_exact(q, p)|`

对于每个距离 `D`，在 `[D-0.5,D+0.5]` 的球壳中采样 512 个玩家位置，并遍历方块在 16³ 子区块中的全部 4096 个位置。图表同时显示平均值和 P95，分别代表典型位置和偏大位置。

## 结果

### 距离-误差

单方块贡献为 1 时：

| 玩家到子区块中心距离 | 平均绝对误差 | P95 绝对误差 |
| ---: | ---: | ---: |
| 1 | 1.310 | 3.229 |
| 2 | 0.247 | 0.403 |
| 4 | 0.0513 | 0.0694 |
| 6 | 0.0254 | 0.0448 |
| 8 | 0.0182 | 0.0438 |
| 10 | 0.0105 | 0.0293 |
| 12 | 0.00559 | 0.0173 |
| 16 | 0.00205 | 0.00657 |
| 20 | 0.00101 | 0.00305 |
| 32 | 0.000239 | 0.000619 |
| 64 | 0.0000294 | 0.0000668 |
| 128 | 0.00000366 | 0.00000810 |
| 256 | 0.000000458 | 0.00000101 |

以绝对误差为标准，平均误差达到：

| 目标误差 | 平均值 | P95 |
| ---: | ---: | ---: |
| ≤ 0.1 | 3 格 | 4 格 |
| ≤ 0.01 | 11 格 | 15 格 |
| ≤ 0.001 | 21 格 | 28 格 |

这说明单方块模型下，误差主要集中在玩家很靠近子区块中心、而源方块位于偏远位置的区域；不需要使用上一版的 32~48 格边界。

### 距离-实际值

忽略性判断只使用实际值 `A_exact`，不使用缓存误差。图中显示所有方块位置和玩家位置样本的实际值平均值、P95，以及缓存值作为对照。

| ---: | ---: | ---: | ---: |
| 1 | 0.0296 | 0.0748 | 1.336 |
| 4 | 0.0282 | 0.0747 | 0.0632 |
| 8 | 0.0217 | 0.0596 | 0.0157 |
| 12 | 0.00877 | 0.0243 | 0.00697 |
| 16 | 0.00431 | 0.0105 | 0.00391 |
| 24 | 0.00181 | 0.00337 | 0.00174 |
| 32 | 0.000998 | 0.00160 | 0.000977 |
| 64 | 0.000245 | 0.000311 | 0.000244 |

| 256 | 0.0000153 | 0.0000162 | 0.0000153 |

按平均实际值，低于 `0.01` 约在 12 格，低于 `0.001` 约在 32 格；按 P95 则分别约为 17 格和 39 格。近距离的极端最大值可能因为玩家位置非常接近方块中心而很高，因此若要保证所有位置都可忽略，应使用最近点距离或 P95，而不能只看平均值。

## 结论

1. `10^4%` 的问题来自把整个 16³ 子区块的 4096 个方块都作为同时存在的源，再拿聚合总值与单点值比较；单方块模型不会有这个放大错误。
2. 对单方块缓存，建议以 P95 绝对误差 `0.01` 为边界时使用 **15 格**作为逐方块计算范围；超过该距离可使用子区块中心缓存。
3. 如果目标是更严格的 `0.001` 绝对误差，逐方块范围提高到约 **28 格**。
4. 忽略性应直接基于 `A_exact` 判断。单方块实际值随源方块贡献线性缩放，若贡献为 `s`，图中的值和阈值比较都乘以 `s`。
5. 平均实际值在近处偏低，是因为方块只有一个而 4096 个位置被等概率遍历；这不表示玩家贴着实际灵气方块时影响很小。近场安全判断应参考 P95、最近距离或直接逐方块计算。
