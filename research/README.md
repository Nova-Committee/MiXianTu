# 设计稿与审计

`research/`
保存设计决策、实现说明和审计记录。当前行为以代码为准，使用方法和数据包格式见 [MiXianTu 文档](https://docs.iafenvoy.com/docs/mod/mxt)。

## 放置与编号

- 新模块、跨模块重构、影响公开契约的改版，以及明确要求先设计的事项，在本目录编写设计稿。文件名使用 `NNN_<主题>.md`
  ，按现有最大编号递增，前面补零至三位。下一篇从 `119_` 开始。
- 设计稿记录代码基准、决定的理由、实现边界和验证结果。设计变更时，在旧稿标明被替代的结论并链接到新稿。
- 审计报告放在 [audit/](audit/)，按模块或主题命名。开发约定见 [AGENTS.md](../AGENTS.md)。
