输入：
- 参考图形：线段集合，或可转化为线段集合的折线/多边形。
- 玩家绘制：笔画点列，可能多笔、断笔、抖动、连笔。

输出：
- 相似度分数 0 到 100。
- 最佳旋转角。
- 调试信息：Chamfer 距离、方向距离、拓扑惩罚、图匹配分数、线段匹配分数、是否回退。

算法逻辑：

1. 预处理
- 玩家绘制先去抖动，去掉距离过近的点。
- 按固定弧长或相对图形尺寸重采样。
- 用折线简化算法提取关键点，例如 RDP。
- 合并距离过近的端点。
- 如果线段之间存在交点，在交点处分割线段。
- 参考图形和玩家绘制都统一表示为三部分：线段集合、采样点云、关键点图。关键点包括端点、交点和简化后的角点。

2. 归一化
- 平移：计算所有采样点的质心，平移到原点。
- 缩放：计算所有点到质心的 RMS 距离，除以该值，使尺度归一。
- 旋转：不要用 PCA 强制对齐，因为对称图形会有歧义。旋转在匹配阶段搜索。

3. 旋转搜索
- 粗搜：0 到 360 度，按可配置步长搜索，例如 5 度。
- 细搜：在粗搜最优角附近小范围搜索，例如正负 5 度，步长 1 度。
- 对每个旋转角，旋转玩家点云，计算与参考点云的距离，取最小距离对应的角度。
- 如果图形对称，记录多个候选角，避免只取一个局部最优。

4. 主评分距离
- 对称 Chamfer 距离：对参考点云中每个点，找玩家点云中最近点，计算距离并平均；再对玩家点云中每个点，找参考点云中最近点，计算距离并平均；两者相加或取平均，作为 Chamfer 距离。
- 方向一致性：为每个采样点估计切线方向。对每个点找最近点后，比较两者切线方向的最小夹角，累加后平均。方向差越小，说明走向越一致。
- 拓扑惩罚：从线段集合中统计连通分量数、端点数、交点数、闭合区域数、总线段数或总长度。比较参考图形和玩家绘制的这些量。差异越大，惩罚越高。对断笔、抖动导致的连通分量差异要软化，不要因为多一个端点就判零分。
- 几何总距离：`D_geo = D_chamfer + w_dir * D_dir + w_topo * D_topo`。权重可调，方向权重初始可设 0.3，拓扑权重初始可设 0.2。所有距离先做尺度归一。

5. 可选图匹配增强
- 构图：节点为端点、交点和简化角点；边为节点之间的线段。
- 节点特征：到质心距离、度数、局部角度分布、到最近节点的距离等。
- 边特征：归一化长度、与相邻边夹角等。
- 在最佳旋转角附近，对玩家图旋转。
- 用匈牙利算法或等价匹配算法匹配节点。节点代价由特征距离和位置距离组成。
- 匹配后计算边匹配率：参考图中相连的节点，在玩家图中是否也相连。
- 图相似度由边匹配率和节点代价共同决定。
- 融合：`D_total = (1 - alpha) * D_geo + alpha * D_graph`。alpha 初始可设 0.3 到 0.5。
- 如果节点数差异过大、匹配代价过高、目标语言缺少图匹配库，或匹配结果明显异常，直接跳过图匹配，退回 `D_geo`。

6. 线段匹配回退
- 如果图匹配太复杂或不可用，使用线段匹配。
- 在最佳旋转角下，对参考线段集和玩家线段集做匹配。
- 每条线段的特征：归一化长度、中点到质心距离、方向角。
- 使用匈牙利算法或贪心匹配。
- 代价由长度差、中点距离、方向差加权组成。
- 匹配后的平均代价转换为线段匹配距离。
- 该距离可作为 Chamfer 的补充，或作为图匹配的替代。

7. 评分映射
- 最终距离 `D_total` 融合几何距离、图匹配距离、线段匹配距离。
- 使用指数衰减映射为分数：`score = 100 * exp(-D_total / sigma)`。
- `sigma` 控制宽容度，小游戏建议偏宽容，初始可试 0.15 到 0.25。
- 最后将分数限制在 0 到 100。
- 不同复杂度图形可以使用不同 `sigma`，但必须可调。

8. 输出
- 返回最终分数、最佳旋转角、各距离分量、是否使用了图匹配或线段匹配回退。
- 空输入、点数过少、玩家只画一个点或极短线段时，返回低分或 0 分，不要崩溃。
- 玩家多画无关线条时分数下降但不归零；少画一条边时分数应明显下降。
