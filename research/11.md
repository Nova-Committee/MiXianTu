# 网文修仙通用核心要素（适配Minecraft模组开发，区分【必加核心】【可选扩展】【适合游戏化改造的点子】）
结合绝大多数凡人流、正统仙侠、修仙网文设定，同时兼顾MC玩法，整理分类，你可以直接挑选组合做成模组机制。

## 一、修为境界（最基础，所有修仙文标配，可直接做成等级系统）
主流两套体系，你任选一套或融合：
### 方案A（经典凡人修仙传体系，受众最广，推荐模组使用）
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫（飞升）
每个大境界再细分：初期/中期/后期/巅峰/圆满

### 方案B（传统简易体系，轻量化模组首选）
引气（炼气）→ 筑基 → 金丹 → 元婴 → 化神 → 渡劫飞升

### 额外变种（很多网文添加）
1. 凡人→先天（武道前置，适合开局凡人阶段）
2. 飞升后：地仙、天仙、金仙、太乙、大罗、道祖（仙界篇）
3. 魔修单独境界：魔种、魔婴、魔主等（正邪分支）

> MC适配思路：修为值=经验条；突破需要丹药+特定条件；失败会掉修为、走火入魔。

## 二、灵根/天赋（开局随机天赋系统，极强可玩性）
几乎所有修仙文标配，决定修炼速度、功法适配：
1. **五行灵根**：金、木、水、火、土
    - 单灵根（天灵根）：修炼最快，稀有
    - 双灵根（地灵根）：优秀
    - 三灵根：普通
    - 四/五灵根（杂灵根、伪灵根）：修炼极慢（凡人流经典开局设定）
2. **变异灵根**（稀有天赋）：雷灵根、冰灵根、风灵根、暗灵根、光灵根
3. 特殊天赋：
    - 道体、先天道胎、混沌灵体、先天剑骨、纯阳体、纯阴体
    - 废灵根/无灵根（可设计特殊路线：炼体、修魔、依靠外力）
4. 负面天赋：噬灵体、劫运缠身（渡劫难度上升）

> MC适配：新建玩家随机roll灵根；可使用道具洗灵根。

## 三、修炼方式（核心循环玩法，模组主要日常内容）
1. **打坐吐纳**：原地持续恢复灵力、缓慢增长修为；需要灵气环境
2. **吸收灵脉/灵气**：灵气浓郁区域修炼效率翻倍（灵地、洞天福地）；贫瘠之地修炼减速
3. **丹药辅助**：快速获取修为（有丹毒！长期乱吃会留下隐患）
4. **功法运转修炼**：修炼对应功法，提升对应属性
5. **闭关**：消耗灵石、资源，长时间持续修炼，外界无法打扰

## 四、灵力/真气系统（资源数值底层）
- 灵力（真气、真元、法力）：释放术法、御剑、施展神通消耗
- 灵压：高修为存在自带气场，低修为靠近会被压制（怪物AI可用）
- 神魂（元神、神识）：
  网文高频要素！探查周围环境、识别宝物、对抗精神攻击、神魂攻击；元婴之后神魂大幅增强。
> MC改造：神识=大范围透视；神魂受伤导致视野模糊、移速降低。

## 五、功法、术法、神通、秘术
### 1. 功法（被动，决定修炼根基）
分为：
- 凡阶→灵阶→玄阶→地阶→天阶→仙阶（品级）
- 属性区分：金木水火土、雷法、剑修功法、魔功、邪修功法、炼体功法
- 功法冲突：同时修炼两种相悖功法会走火入魔

### 2. 术法（常规技能，消耗灵力释放）
火球术、水盾、风刃、土遁、木愈术、隐身术、瞬移、御雷术等基础五行法术

### 3. 神通（高阶能力，元婴/化神解锁，威力巨大）
大范围毁灭法术、领域、身外化身、空间神通、法天象地

### 4. 秘术/禁术
代价巨大的能力：燃烧修为换取爆发、献祭寿元、神魂自爆，使用留下永久副作用

### 分支路线（网文热门派系，你可以做成玩家发展分支）
1. **剑修**：主修剑意，御剑飞行、御剑术，攻击力高；重剑鞘、飞剑
2. **炼体修（体修）**：不修灵力，淬炼肉身，近战极强，抗打击；依靠灵药、凶兽血肉淬炼
3. **丹修**：擅长炼丹，战斗力偏弱，靠丹药、傀儡作战
4. **器修（炼器师）**：打造法宝、法器
5. **符修**：绘制符箓，储存法术，应急释放
6. **阵修**：布置阵法，防御、困敌、聚灵、杀阵
7. **魔修/邪修**：功法特殊，可以掠夺他人修为、神魂；天道压制，容易被正道追杀
8. **兽修（御兽）**：收服妖兽、灵宠，签订契约协同作战

## 六、宝物、法器、灵宝体系（装备系统，对应MC装备）
品级通用分级：凡器→法器→宝器→灵器→灵宝→先天灵宝→仙器→神器
- **法器**：普通修仙者使用，需要灵力驱动
- **法宝**：自带灵性，可以温养；部分能自主护主
- **本命法宝**：修士以神魂祭炼，与自身绑定，损毁重创元神（核心剧情要素）
- **飞剑**：剑修本命首选
- **储物法宝（储物袋/储物戒）**：重中之重！几乎所有修仙文必备，对应拓展背包
- **灵舟、飞辇**：大型飞行载具，多人乘坐

附加设定：
- 宝物认主、滴血祭炼、解除认主
- 灵气充沛才能催动高阶法宝，修为不足强行催动会反噬

## 七、丹药、灵药、天材地宝（资源循环）
1. **灵药**：年份设定（百年、千年、万年灵药），生长在灵气充足区域
2. **丹药品级**：凡丹、灵丹、仙丹；常见丹药：
    聚气丹、筑基丹、金丹突破丹、疗伤丹、解毒丹、洗髓丹、固元丹、延寿丹、渡劫丹
3. **丹毒设定**：频繁嗑药堆积丹毒，阻碍突破，需要特定丹药排毒（增加策略性）
4. **天材地宝**：先天果实、地心火髓、九天玄冰，用于炼丹、炼器、突破境界

## 八、灵石与灵矿（通用货币+能源）
网文标准硬通货：灵石
- 下品灵石→中品→上品→极品灵石；可以互相兑换
作用：
打坐消耗、驱动阵法、法宝充能、交易货币、布置传送阵
配套：灵矿、晶脉，可以开采生成灵石；存在枯竭灵脉。

## 九、妖兽、灵植、灵禽（世界生物）
1. 妖兽分级：对应修士境界（炼气妖兽→渡劫妖兽）
2. 妖兽内丹：核心掉落材料，炼丹炼器必需品
3. 上古异种、神兽、凶兽、异兽
4. 灵植：可以种植，模组可以做农耕修仙玩法

## 十、阵法（内容扩展重要模块）
常见阵法用途：
聚灵阵（加速修炼）、防御护山大阵、困杀阵、幻阵、传送阵、迷踪阵、炼阵
材料：阵旗、阵盘、灵石维持能量。

## 十一、飞行与移动手段
1. 御器飞行（踩飞剑、法宝飞行，筑基解锁最经典设定）
2. 遁术：土遁、水遁、空间瞬移
3. 灵舟长途跨区域移动

## 十二、天劫、心魔、天道规则（突破风险，增加难度）
1. **天劫**：大境界突破触发（筑基劫、金丹劫、飞升雷劫），雷劈、风火大劫；渡劫失败身死道消或修为大跌
2. **心魔**：突破、闭关、战斗时出现，考验心神，心魔入侵会走火入魔，堕入邪道
3. 因果、业力：邪修杀生过多，天劫威力提升；正道积善可略微削弱天劫

## 十三、势力与NPC阵营（适合加村庄、宗门NPC）
经典修仙势力结构：
- 大宗门、隐世门派、魔道宗门、散修联盟、上古世家、妖族部落、邪修据点
宗门设定：外门弟子→内门→核心弟子→长老→宗主；有宗门任务、藏经阁、贡献兑换功法宝物

## 十四、其他高频经典网文设定（可选加分项）
1. **寿元**：凡人百年，筑基增寿、金丹大幅延长寿命；寿元耗尽不突破直接坐化（强力长线压力机制）
2. **轮回、转世修士**：保留部分前世记忆与天赋
3. **秘境、上古遗迹、上古洞府**：周期性开放，里面有宝物、危险禁制（副本系统）
4. **空间裂缝、小世界、洞天福地**：独立地图区域
5. **拍卖会**：修士交易稀有宝物
6. **夺舍**：修为高深者肉身损毁，抢占他人躯体（邪修经典能力）
7. **血祭、炼尸、蛊术**：邪修专属玩法
8. **灵宠契约**：平等契约、主仆契约、共生契约
9. **道号、道途感悟（悟道）**：参悟天道法则，提升境界上限
10. **上古传承**：遗迹获得前人功法、记忆
