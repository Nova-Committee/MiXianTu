# 注册表协作规范

领域 behavior 注册表已移除。所有可配置回调统一使用现有 Action 系统：

- `EntityAction`：实体生命周期、修炼、突破、天劫、秘境等行为。
- `BlockAction`：阵法和工作台方块位置行为。
- `BiEntityAction`：契约等同时需要施法者与目标的行为。
- `ItemAction`：物品精炼、物品绑定和物品技能行为。

原先通过 `Kind` 在一个 behavior 中分支的场景，改为多个明确的 action 字段，例如成功与失败分别使用 `success_action`、`failure_action`。同时作用于实体和方块的场景使用两组字段，例如炼丹配方的 `success_action` 与 `success_block_action`。

Action 字段可以写单个对象，也可以写对象数组；数组按顺序执行。Action 的 `type` 由固有 Action 类型注册表分派，具体参数直接内联在同一个对象中。数据包不再引用任何 `*_behavior` 注册表或行为 ID。
