# 光束粒子效果设计

> 当前形状、终端、边界与 GPU 实例化见 [`99_光束粒子渲染设计.md`](99_光束粒子渲染设计.md)。本文保留最初方案；字段与单粒子承载整柱的入口继续沿用。

## 目标

新增 `mxt:light_beam` 粒子，表示一根沿世界 Y 轴延伸的竖直光束柱。粒子选项携带横向偏移 `x` / `z`、竖直范围 `y_min` / `y_max`、颜色、宽度、流动方向和流动速度，服务器只需发送一份粒子选项即可让客户端持续绘制整根光柱。

## 形状与动画

粒子使用现有的径向柔光粒子贴图，客户端把光束拆成有限数量的上下堆叠 billboard 片段。每个片段绘制外晕、内晕和亮芯三层，并把时间与片段的归一化高度送入相位函数；相位沿 Y 轴移动，所以流动方向只能是 `up` 或 `down`，不会引入水平漂移。全层使用满亮光照坐标，得到整体发光效果。

## 参数边界

- `x` / `z` 和 `y_min` / `y_max` 是相对粒子生成点的偏移，`y_max` 必须大于 `y_min`。
- `color` 使用 ARGB；默认是淡黄色 `#FFFFE8A8`。
- `width` 是中心亮芯的直径，外晕按固定倍数扩展。
- `flow_direction` 只接受 `up` / `down`；`flow_speed` 为每 tick 的动画速度。
- `lifetime` 使用粒子常规 tick 生命周期，默认 40 tick。

## 取舍

这里不单独引入新的 GPU 管线：粒子系统已经为自定义粒子提供批量四边形提取和排序，复用它能保持 `/particle`、数据包 `ParticleEffect` 和网络同步兼容，也避免再次引入动态 UBO、天空深度和透明合成问题。多片段与三层光晕只增加一次粒子提取中的顶点数量，远低于为每根光束创建实体或独立 framebuffer 的成本。
