# AUI 多主题与样式分层设计

## 目标与范围

提供宣纸朱砂、青玉竹简、玄墨鎏金三套外观，由 MiXianTu 客户端配置统一选择。覆盖本体 AUI 页面，以及复用本体页面宿主和共用样式的工作站附属；Saturn 的原生轮盘、原版容器与世界渲染不在范围内。

三套外观共用布局、字体、交互和槽位几何，不复制三份页面。默认采用宣纸朱砂。

## 样式分层

- `common/theme.css` 负责字体、布局、控件、状态、槽位和装饰层；通过相对 `@import` 引入三份主题文件。
- `common/themes/parchment.css` 提供缺省变量；`jade.css` 和 `ink-gold.css` 用 `body[data-mxt-theme]` 覆盖同名变量。
- 子 CSS 仅声明颜色、渐变及装饰资源变量。页面专属 CSS 使用变量，不能自行复制调色板。
- 轻量 SVG 提供角纹、山水、云纹、法阵、人物预览暗纹与装备轮廓。山水放在人物信息区与灵气工作台留白处，不覆盖文字、物品和图表。

当前 AUI 的 SVG 解码支持文件内部的 `style` 和 `currentColor`，但不会把页面的 CSS 变量或文字颜色传入独立图片。单色图形可用 `mask-image` 与背景色复用，但需要遮罩合成。当前静态装饰采用预配色 SVG，直接作为背景纹理缓存，未引入遮罩层或修改 AUI。

描边继续使用内阴影，装饰不参与盒模型。主题不增加面板或槽位的实际边框与内边距，保留原生物品的单像素内缩。三种主题均使用 Minecraft 位图字体。

## 文本与绘制边界

普通文字由 `div` 等 DOM 容器承载；静态翻译保留容器内的 `translation`，富文本保留内部文本段，由 CSS 统一控制字体、对齐与语义色。数据自带颜色在当前背景上调整明度，保留色相并保证可读性；进度填色、物品与原版 tooltip 保留原有规则。

Java 不再保存一份固定的界面调色板。裂隙编辑器和耗时图表仅用 Canvas 绘制几何，提交绘制任务前从当前页面解析颜色，回调使用不可变调色板，避免异步读取 DOM。

## 配置与生命周期

配置入口为客户端配置「界面外观 → 界面主题」，默认宣纸朱砂。页面每次打开、窗口缩放重建或资源重载重新绑定时，共用宿主在绑定前把当前选择写入页面 `body`。已打开的文档不做逐帧配置同步；切换后关闭并重新打开页面即可生效。

每个文档持有自己的主题属性，不使用全局可变调色板，也不为换肤重建菜单。附属通过现有共用宿主和样式引用继承配置，不各自增加一套主题选择。

## 验证与限制

已实现主题、配置、配色适配和 SVG。主代码与测试代码编译、打包及双语文档构建通过。独立程序使用实际 AUI 验证九个本体页面、三种窗口尺寸、三主题及切回默认主题，检查面板和物品几何、DOM 文本、动态颜色对比度、配置往返与文档隔离；25 张 SVG 已通过 AUI 解码。

新增 `verify/aui/themes`、`verify/aui/theme_text`、`verify/aui/theme_config` 三组 GameTest。三组新增主题测试与十一组既有 AUI、灵气条目和图表回归共 14/14 组 GameTest 已通过。独立 AUI 检查合计 35,280 项通过。图表夹具已按全局 Source 索引构造快照，并独立保存完整 tick 标记。游戏客户端尚未实跑，实际画面、真实菜单交互和附属组合仍需运行验证。
