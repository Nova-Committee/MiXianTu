# 觅仙途

[English](README.md) | **简体中文**

觅仙途是一个**修仙模组框架**，提供修仙玩法所需的**通用规则与运行时**，涵盖修炼、灵气环境、境界与资源、技能、阵法、天劫及经济，不预设具体的世界观与数值。

框架包含通用物品与方块。数据包、KubeJS 和内容模组提供成长体系、平衡数值及玩法定义，再通过 MiXianTu 的数据表与物品绑定接入框架。

- **玩家**：单独安装本体可获得框架物品、饰品槽位、HUD 与命令；具体玩法取决于使用的数据包或内容包。
- **内容与模组作者**：通过数据包、KubeJS 或 Java API 定义修炼规则、灵气分布、技能、阵法、工艺与物品绑定，无需修改本体。

**项目仍在开发中。数据包格式及其他接口尚未定型，更新可能不再兼容旧存档或旧数据包。
可能导致崩溃或数据丢失的变更会在更新日志中明确说明。**

## 功能特性

### 面向玩家

- **按键**：`C` 切换修炼模式，`Z` 打开人物信息面板，`R` 打开轮盘，`V` 使用选中条目，方向键切换轮盘页面。
  「交换主手与背部武器槽位」默认未绑定。所有按键均可在控制设置中修改。
- **界面**：可配置的 12 格主轮盘，根据手持物品、法器与契约灵兽生成的技能页面，以及资源条和灵气 HUD。
- **方块**：灵气工作台、兑换站、交易站、支票台、展示架、灵石矿石与灵石块。灵植定义可为已有方块添加生长与收获规则。
- **物品**：下品到极品灵石、灵铁、灵木、朱砂等材料；灵戒、灵石袋、灵力容器、鉴定镜、功法书、玉简、空白符纸、
  符笔、符箓、契约卷轴、御兽铃、灵兽袋、阵盘、木令牌、石令牌和秘境令牌等通用物品。
- **符箓**：铭刻后的载体可储存灵气，在充能或使用时发动技能；定义控制目标、费用、消耗与耐久，本体同时提供共享的符笔、颜料与空白符纸。
- **展示架**：展示物品，并以展示架自身位置激活充能后的符箓。
- **槽位**：提供 Curios 装备槽位、角色身上的装备渲染，以及与主手交换装备的快捷键。
- **命令**：`/mxt` 系列命令提供注册表校验、资源与灵气查询、修炼状态和突破等功能，`/display` 用于装备展示。

具体的境界数值、灵气分布、技能、阵法与配方由数据包或内容包提供，单独安装本体不会形成完整的成长流程。

### 面向数据包、模组与整合包作者

- **数据包**：通过原版数据包注册表定义资源、境界、灵气、技能、阵法、工艺与经济等规则，加载时校验并同步至客户端。
- **物品接入**：将已有物品绑定至技能、丹药、资源与灵气燃料；通过物品组件保存各堆物品的品质、元素、丹药数据与功法阅读进度。
  灵石可接收持有者灌注的灵气。
- **KubeJS**：提供行为、条件、费用、数值提供器、目标选择器、触发器匹配器与战利品回调等扩展点，
  以及 `MxtEvents` 服务端生命周期事件和支持发布、订阅自定义触发器信号的 `MxtTriggers`；可先用脚本注册物品，再通过绑定表接入。
- **Java API**：提供数据表注册、附件、网络、界面与客户端渲染接口。

更多说明见[文档教程](https://docs.iafenvoy.com/docs/mod/mxt/tutorial/)。

## 常见问题

### 需要哪些前置？

| 依赖                          | 要求               |
|-----------------------------|------------------|
| Jupiter、Saturn、ApricityUI   | 必需，需单独安装。        |
| Curios、Ponder、Catnip 及其他内嵌库 | 已内嵌，无需另行安装。      |
| Reincarnation               | 可选，提供寿元与转世功能。    |
| KubeJS                      | 可选，用于脚本内容。       |
| JEI、Jade                    | 可选，提供配方浏览与游戏内提示。 |

安装所选可选模组时，也需满足其各自的依赖要求。

### 装了本模组进游戏为什么没有变化？

本体只提供框架、通用物品、槽位、HUD 与命令，不包含具体的境界数值、技能或配方。
需要搭配数据包或内容包（包括通过 KubeJS 编写的内容）才能形成实际玩法。
