# 觅仙途

[English](README.md) | **简体中文**

觅仙途是一个**修仙模组框架**，它提供修仙玩法所需的**通用规则与运行时**
——修炼、灵气环境、境界与资源、技能、阵法、天劫、锻造、炼丹、经济——但不预设具体的世界观与数值。

具体的物品、方块和配方由数据包、KubeJS 或其他内容模组提供，再由 MiXianTu 的数据表与绑定表赋予玩法。

- **玩家**：单独安装本体只会得到框架物品、饰品槽位、HUD 与命令；实际能玩到什么，取决于你使用的数据包或内容包。
- **内容与模组作者**：可以用数据包、KubeJS 或 Java API 定义自己的修炼规则、灵气分布、技能、阵法、工艺和物品绑定，不需要改动本体。

**项目仍在开发中。数据包格式等尚未完全确定，更新时可能不再兼容旧存档和旧数据包。在更新日志中会明确提及会导致崩溃或数据丢失的变更。
**

## 本模组提供了什么

### 玩家可使用功能

- **按键**：`C` 切换修炼模式，`Z` 打开人物信息面板，`R` 呼出轮盘（技能与灵气的唯一触发入口）；另有「交换主手与背部武器槽位」默认未绑定。以上均可在按键设置中修改。
- **界面**：12 扇轮盘（指针朝哪一扇就选哪一扇，选中的名字写在正中间，聊天栏打 `/wheel` 打开配置界面摆 12 个扇区）、资源条、灵气浓度 HUD。
- **方块**：灵气工作台（跑灵气合成配方，取出产物时扣除灵气）、锻造台、兑换站、交易站、支票台、展示架，以及灵石矿石与灵石块。
- **物品**
  ：下品到极品灵石、灵铁、灵木、朱砂等材料；灵戒、灵石袋、灵力容器、鉴定镜、功法玉简、空白符纸、符笔符墨与符箓（铭刻定义后灌注灵气，灌满即发动并烧掉一张）、契约卷轴、御兽铃、灵兽袋、阵盘、木令牌与石令牌、秘境令牌、召回符等通用物品。
- **符箓**：用符笔把道法定义铭刻到载体上，再灌注灵气；账单里的灵气灌满那一刻铭刻的道法全部发动，并消耗一张载体。没发动成、或账单为空的符可以右键直接发动，
  `invoke_on_use: false` 的定义则只回应被灌满。
- **展示架**：任何物品都能摆在展示架上展示；架上的符被灵力射线灌满时会**就地发动，并以展示架的位置作为激发地点**——公式里的
  `block_x`/`block_y`/`block_z`、范围选择器的圆心和"从哪里射出"都用它，而不是填符的人所在的位置。
- **槽位**：背部武器、腰部物品和功法三个饰品槽位，可用快捷键与主手交换。
- **命令**：`/mxt` 系列（数据表校验、资源与灵气查询、修炼状态、突破等）与 `/display` 装备展示。

具体玩法内容——境界数值、灵气分布、技能、阵法与配方——都由数据包或内容包提供，单独安装本体不会得到完整流程。

### 数据包/模组/整合包作者可使用功能

- **数据包**：用原版数据包注册表定义资源、境界、灵气、技能、阵法、工艺、经济等规则，加载时校验并同步到客户端。
- **行为与条件**：实体、双实体、方块、物品和伤害五类行为与条件，可在数据包中自由组合。
- **数值**：常量、exp4j 表达式或结构化数值提供器，可读取等级、资源等上下文变量。
- **物品接入**：通过绑定表把**已有的**物品接入武器、丹药、功法、资源与灵气燃料玩法，方便和其他模组进行联动；实现
  `AuraItemAccess` 的物品（灵石等，键是 `Holder<Aura>`）还能按住右键把自身灵气灌注进去。
- **KubeJS**：提供行为、条件、Cost、数值提供器、技能目标选择器、触发器匹配器与战利品回调，`MxtEvents`
  服务端生命周期事件，以及发布/订阅自定义触发器信号的 `MxtTriggers`，可先用脚本注册物品再交给绑定表处理。
- **Java API**：数据表注册、附件、网络、界面与客户端展示的接口。

## 常见问题

### 装了本模组进游戏为什么没有变化？

本体只提供框架、通用物品、槽位、HUD 和命令，不包含具体的境界数值、技能和配方。需要搭配数据包或内容包（包括用 KubeJS
编写的内容）才会出现实际玩法。

### 需要哪些前置？

Jupiter 为必需前置，其他必须前置均已打包进模组本体；KubeJS 只在你想用脚本注册内容时需要。JEI 和 Jade 为可选兼容模组，不装也能正常游玩。

### 如何临时关掉某个内容？

在 `mxt:disabled` 标签中加入对应条目即可，被停用的定义不会参与玩法，无需删除数据包文件。

### 可以做自己的内容包并分发吗？

可以基于本框架制作内容包，分发不受任何限制。
