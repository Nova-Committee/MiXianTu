# 术语与口径

**术语固定。** 载体与定义一律写「符箓」（`talisman`），配套「符纸」「符笔」，笔上的颜料存量就叫「颜料」（`mxt:brush_pigment`，主资源包里由朱砂 `cinnabar` 供应）；**「符篆」是误用、「符墨」那件物品（`talisman_ink`）已删除**，两者都不得出现在文案、注释或文档里。灵气工作台的配方族叫**灵气合成**（`mxt:spirit_shaped` / `mxt:spirit_shapeless`），方块叫**灵气工作台**（`spirit_crafting_table`）。灵根（`spirit_root`）与体质（`physique`）是两套东西；功法（`technique`）与技能（`ability`）与进度等级（`progression`）是三层；`resource` 是**数值**系统、`aura` 是**灵气身份**（详见 `docs/docs/datapack/conventions.md` 与 [house-rules.md](house-rules.md)）。
